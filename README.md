# Forgejo 镜像

> **这是一个只读镜像。**  
> 官方源托管在 **[Codeberg](https://codeberg.org/forgejo/forgejo)**。

## 📦 这是什么？

本仓库是官方 [Forgejo](https://codeberg.org/forgejo/forgejo) 仓库的自动镜像。  
它仅为方便而存在。**所有开发、问题、拉取请求和讨论都在 Codeberg 上进行。**

## 🔍 如何查看代码

镜像的源代码位于 **`main`** 分支（以及其他分支/标签）。  
由于此默认分支仅包含镜像配置，请切换到 `main` 分支浏览代码。

## 🔄 同步状态

- 同步来源：`https://codeberg.org/forgejo/forgejo.git`
- 频率：每 30 分钟（UTC）
- 范围：仅源代码（分支、标签、提交历史）

较早版本（v8.0 及之前）采用 MIT 许可证。  
请参阅源仓库获取完整许可证文本。
